# CRICKSTATS - Brainstorming & Ideation

## Problem Statement
Cricket player statistics are often kept in scattered sheets, which makes it hard to track individual performance across matches.

## Idea
CRICKSTATS is a Salesforce Lightning application that stores player and match data in one place and calculates career statistics automatically.

## Proposed Solution
- Player and Match Performance objects to store data
- Roll-up summary fields to calculate totals automatically
- Screen Flows to view players by team
