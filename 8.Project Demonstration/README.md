# CRICKSTATS - Project Demonstration

Demo of the CRICKSTATS Salesforce Lightning app:

1. Players tab: Player record for MS Dhoni with roll-up summary fields and profile photo
2. Match Performances tab: CSK vs RCB and CSK vs MI records
3. Player Flow on the Home page: select a team to see its players in a data table with photos

Screenshots of each step are in 6.Project Testing.
