# CRICKSTATS - Project Development Phase

## Built in Salesforce
- Custom objects: Player, Match Performance
- 22 fields on Player, including roll-up summary fields: Matches Played, Number of 50's, Number of 100's, Total 4's, 6's, Runs, Overs, Wickets, Stumpings, Catches
- AVG Score formula field
- Player Screen Flow with a data table showing all fields, including the profile photo
- Player Flow placed on the Home page of the CRICKSTATS app

Full details are in 7.Project Documentation.
