# CRICKSTATS - Requirement Analysis

## Functional Requirements
- Store player details (name, number, date of birth, role, batting style, bowling style, nationality, team, profile photo)
- Record match performance (runs scored, balls faced, fours, sixes, stumpings, catches)
- Calculate totals and averages automatically for each player
- Show players by team on the Home page

## Technical Requirements
- Salesforce Developer Edition org
- Lightning App, custom objects, roll-up summary fields, Screen Flows
